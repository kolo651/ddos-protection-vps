## 先分清三种"防护"，再谈价格

**一、什么都不防，被打就黑洞。** 大多数便宜 VPS 属于这类。攻击流量打满机房带宽，机房为了保住同段网络的其他客户，直接封你的 IP，常见封禁从半小时到一天。你付出的是停机时间，外加解封后换 IP、改解析、搜索引擎重抓的一串连锁麻烦。

**二、机房基础防护。** 也就是商品页上那句"含 DDoS 防护"。机房入口有基础过滤，能吃掉一部分小流量 UDP Flood、SYN Flood，但阈值一般不公开，也没人告诉你到底是多少 Gbps。DMIT 的 Tier 1、Eyeball、Premium 三条线，官方标注的都是 Standard DDoS Protection，属于这一档。

**三、牵引式清洗。** 攻击流量不直接进机房，先用 BGP 牵引到上游清洗网络，逐包过滤后再把干净流量回注到你的服务器。DMIT 的 sPro 系列走这条路，官方标注 5Tbps+ Always-On。这个数字是清洗平台侧的容量，不等于给你单机预留了 5Tbps；但对挨打的人来说，感受到的差别就是"被打了站还在"和"被打了站没了"。

## 打死你的攻击分两层，钱要花在对应那层

流量型攻击（UDP Flood、SYN Flood、NTP/DNS 反射放大）拼吞吐，几百 Gbps 的放大流量能把小机房的整条上行打满，这类靠上游清洗解决。

CC 攻击是另一回事。它用看起来完全正常的 HTTP 请求去打搜索页、登录接口、动态页面，带宽可能只占几十 Mbps，但你的 CPU 和数据库先撑不住。清洗平台主要在 L3/L4 干活，对应用层请求的判定能力有限，这层通常还得靠 CDN、WAF、接口限频和源站加固来兜。

所以别把"高防 VPS"当成万能药：它专治流量型攻击，应用层的事得另外配。

## 挑高防 VPS 时，值得追问商家的五个问题

1. **这个数字是单机阈值，还是集群共享容量？** 宣传页写"500G 高防"的低价套餐，很多是整池共享，单机实际只有十几 G。
2. **有没有 pps 口径？** 小包洪泛下 100Gbps 可能对应数十亿 pps；只写 bps 不写 pps 的方案，遇到小包攻击照样卡。
3. **超过阈值之后怎么处理？** 黑洞、限速、自动升级弹性防护，这三种体验差别很大。
4. **清洗中心在哪里，会不会把正常访问的延迟拉高？** 面向中国大陆用户的业务尤其要看这条。
5. **计费口径是什么？** 清洗流量、回源流量、超量限速还是计费，都得买之前问清。

> 一个简单判断法：能把"检测—牵引—清洗—回注"这条链路说清楚，并且给出单机口径和测试 IP 的方案，基本靠谱；只丢一个很大的 G 数、其余全靠文案的，先打个问号。

## 高防买回来，还有三件事得自己做

高防解决的是"流量进不来打死你"，剩下的漏洞是自己开的。

第一，别让源站 IP 裸奔。域名直接解析到源站，攻击者拿源站 IP 一打，清洗那一层等于白买。走 CDN 或反向代理，回源只放行可信节点的 IP。

第二，基础加固别省。改掉默认 SSH 端口、关掉 root 直连、按需开 fail2ban，这三步花不了半小时，能挡掉绝大多数自动化扫描。

第三，上监控告警。CPU、连接数、带宽打阈值就应该有通知，别等用户投诉才发现站已经挂了半小时。

## 常见问题

**5Tbps 是给我这台机器独享的吗？**
不是。这个量级描述的是上游清洗平台的容量，你的入站流量被牵引到那张网里过滤。真正决定你被打了会不会掉线的是清洗触发是否及时、回注链路是否稳定。

**高防 VPS 会不会拖慢正常访问？**
取决于清洗中心的位置和回程线路。单纯绕远清洗确实会加延迟，所以像 sPro 这种"入站走 Cloudflare、回程走 CN2 GIA"的设计，就是为了不让回程吃亏。

**个人博客有必要上高防吗？**
一个月访客几十人的展示站，用不上。但只要你的站有在线成交、有账号体系、或者处在竞争激烈的行业里，被打一次的时间损失通常就超过一年的防护预算。

**香港节点是不是比洛杉矶更能抗 D？**
香港的优势是对中国大陆和亚太的低延迟，不是防御容量。预期会遇到超百 G 的攻击，或者需要全球覆盖，美国节点加 Anycast 清洗更稳；香港更适合承载需要低延迟的那部分业务。

买之前最有用的一步，是拿官方测试 IP 自己跑一遍 ping 和 traceroute，看你目标用户的线路到底怎么走。
